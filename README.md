# SecureM (SM)

> **EN:** An independent open-source Android browser/wrapper designed for enhanced local privacy and sandboxed web sessions.  
> **RU:** Независимый открытый Android-контейнер (браузер) для изолированного запуска веб-интерфейсов с повышенным контролем приватности.

---

## 📌 Назначение проекта / Purpose of the Project

Данное программное обеспечение разработано исключительно в **образовательных, исследовательских целях и для демонстрации технологий** (Educational & Research Use).

Проект представляет собой легковесный специализированный браузерный контейнер (WebView Sandbox), который:
* Не модифицирует исходный серверный код или сетевые протоколы сторонних ресурсов.
* Не обходит защитные механизмы, аутентификацию или технические средства защиты (ТЗПЧ).
* Ограничивает доступ веб-страниц к системным ресурсам устройства (камера, геопозиция, микрофон, файловая система) исключительно локально на стороне пользователя.
